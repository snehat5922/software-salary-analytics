# 💼 Software Salary Analytics Dashboard

An interactive and professional data analytics dashboard built using **Python, Streamlit, Pandas, and Plotly** to analyze software industry salary trends, company insights, job roles, and location-based compensation patterns.

---

## 📌 Project Overview

This dashboard provides comprehensive insights into software industry salary data through interactive visualizations and business intelligence metrics.

The application helps users:

* Analyze salary distributions
* Compare company compensation
* Identify top-paying job roles
* Explore location-wise salary trends
* Evaluate company ratings and salaries
* Generate actionable insights through analytics

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/your-username/software-salary-analytics.git

cd software-salary-analytics
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run Application

```bash
streamlit run app.py
```
